# 精选本地样例

仅选择两组 `store-v4-ima` 真实运行结果：大学新生小红书、差旅办公公众号。两组原记录均使用 ima，并在人工修订后由独立模型核验通过。文案保存于 2026-10-18；本文及 JSON 中的产品参数是历史结果转录，不是实时销售资料或新的实测结论。

`selected-works.json` 包含任务输入、最终文案、原配图方案的文字说明和历史核验说明。省略知识库原件、原图、账号信息、内部 ID、原始响应和来源快照。没有上传第三组本地回退结果或测试夹具。

在安装后端依赖、构建前端后运行：

```powershell
.\.venv\Scripts\python.exe scripts/run_demo.py
```

访问 `http://127.0.0.1:8767/staff`，用户名 `demo_staff`，初始密码 `ZhikeDemo2026!`。这是专门创建的公开演示客服账号，没有管理员权限；不对应原有本地或云端账号。

数据只写入 `tmp/public-demo/`，不会读取或覆盖原 `data/store.db`，也不会重置已有演示账号的密码。服务仅监听本机。入口明确清空外部模型和 ima 凭证，不产生模型调用；导入的案例显示为待检查的历史样例，支持阅读及草稿导出。原稿的历史通过状态保存在说明字段中，不沿用为这个删减副本的当前核验状态。

如要重新生成、补齐图片或进行事实核验，请按根目录 README 配置独立的正式环境，并取得相应资料权限；此样例包本身不包含那些依赖。
