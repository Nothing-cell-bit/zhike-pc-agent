# 模型与 ima API 配置手册

仓库只提供程序和空值示例，不包含团队实际使用的模型服务地址、API Key、ima Client ID 或 ima API Key。各运行者须自行取得服务权限并在自己的电脑配置。不要把真实配置填入本手册或 `.env.example`。

## 1. 准备两个本地私有文件

在仓库根目录创建 `.env` 和 `.env.ima`，与 `README.md` 同级。首次可复制 `.env.example` 为 `.env`；已有文件时只编辑所需字段，不覆盖原文件。

`.gitignore` 已忽略 `.env`、`.env.ima` 及其他 `.env.*`，仅允许空值示例 `.env.example`。打包工具另外使用白名单，不会打入这两个私有文件。

## 2. 在 `.env` 配置文本模型

```dotenv
TEXT_API_BASE=
TEXT_API_KEY=
TEXT_MODEL=qwen3.8-27b
```

| 变量 | 本机填写内容 |
| --- | --- |
| `TEXT_API_BASE` | 你获准使用的 OpenAI 兼容服务基础地址，包含 `/v1`；不要填完整 `/chat/completions` 路径 |
| `TEXT_API_KEY` | 该服务颁发的 API Key，不能用账号昵称代替 |

`TEXT_MODEL` 为服务商提供的模型 ID，默认 `qwen3.8-27b`。需求分析、营销生成与核验使用当前配置的文本模型，核验记录保存实际使用的模型名。模型须支持 OpenAI 兼容的 `/chat/completions`、系统消息、非流式调用和 JSON 对象输出；更换后应重新验证业务结果。

服务地址和密钥只填在你自己的 `.env` 中，不在公开文档中写团队的真实接口地址。未配置时会显示失败原因，不会生成模拟答案。

### 在线自行配置（管理员）

打开[线上工作台](https://nothingk-zhike-pc-agent.ms.show/staff)，管理员登录后，在左下角账号菜单进入「管理设置 → 服务连接 → 语言模型」。

1. 填写 API 基础地址（如服务商的 HTTPS 地址加 `/v1`）、准确模型名称和 API Key，不填完整 `/chat/completions` 路径。
2. 点击「保存模型配置」，后续请求立即使用新配置，无需重新部署。已经运行的单次请求保留原配置。
3. 点击「测试当前已保存配置」，执行一次简短聊天并验证 JSON 响应。测试可能消耗少量额度；通过只证明接口可调用，不代表内容质量已验收。
4. 密钥不回显；同一基础地址留空可保留密钥，更换地址必须重新填写。可用「恢复部署默认配置」删除自定义配置，恢复平台部署变量。

自定义配置只保存在服务端 `STORE_DATA_DIR/private/text-model.json`，使用私有持久目录和原子写入，不进入业务数据库、普通数据库备份、公开 Git 或源码包。Linux 私有文件权限为 600。不要分享该文件；完整运行目录备份同样应按含凭证资料保护。

自定义接口只接受公网 HTTPS 443 端口；不支持本机、内网、元数据地址或带查询参数的地址。每次请求校验并固定公网解析地址，禁止跟随跳转。配置云端可直接访问的服务后，文本 AI 不再依赖个人电脑和临时隧道。当前默认仍是原认证隧道，未切换前仍需电脑开机。已安装的私有产品缓存保持原样；新机器初始化缓存仍需单独准备资料。

## 3. 在 `.env.ima` 配置指定知识库访问

```dotenv
IMA_OPENAPI_CLIENTID=
IMA_OPENAPI_APIKEY=
MARKETING_KNOWLEDGE_SOURCE=ima_first
```

1. 使用自己的 ima 账号登录客户端，按赛题手册二维码加入“任德耀新建华为PC知识库”，确认能打开具体产品资料和图片。
2. 使用同一账号进入客户端的 Claw 配置或 [ima 接口凭证页面](https://ima.qq.com/agent-interface)，取得 Client ID 和 API Key。
3. 仅在本机 `.env.ima` 对应空值后填写这两项。应用直接调用 ima 只读 OpenAPI，不需要将官方 Skill、凭证或知识库原件上传到 GitHub/魔搭。
4. 不需要猜填知识库 ID；程序按指定库名查询。产品目录映射和本地产品选择仍需有权使用的知识包，按 README 导入。

| 知识模式 | 行为 |
| --- | --- |
| `ima_first` | 优先 ima，读取失败时整体回退本地；作品记录实际来源和原因，推荐日常演示使用 |
| `ima` | 只使用 ima，调用失败即停止；适合明确验证 ima 来源时使用 |
| `local_zip` | 仅使用本地知识包，不作为 ima 图源证明 |

设置了凭证只表示“已配置”。必须新建真实营销任务，检查作品的实际来源、图片引用和核验记录，才能判断接口是否成功。`local_zip` 或回退结果不能计为 ima 成功。

## 4. 魔搭生图可选配置

若需要调用云端背景生图，在 `.env` 中填写 `MODELSCOPE_IMAGE_API_KEY`。可选变量为 `MODELSCOPE_IMAGE_BASE_URL` 和 `MODELSCOPE_IMAGE_MODEL`，代码默认使用魔搭官方推理地址和 `Qwen/Qwen-Image-2.1-Turbo`。`MODELSCOPE_ACCOUNT=NothingK` 仅是显示标记，不等于凭证权限通过。

魔搭现已运行原网站，实际运行凭证仅配置在平台私有密文变量 ZHIKE_PRIVATE_CONFIG。文本模型使用经用户授权的临时认证隧道，详见 [部署说明](DEPLOYMENT.md)。没有生图权限时，可以使用已有实图本地合成海报。Git 上传凭证与推理 API Token 的权限可能不同，不能把某一项成功当作另一项也可用。

## 5. 生效顺序与验证

读取优先级：**管理员自定义配置 → 进程环境变量 → `.env.ima` → `.env`**（自定义项只影响文本模型）。同名环境变量已在进程中设置时，修改文件不会覆盖它；`.env.ima` 只保存 ima 所需项，避免干扰常规文本配置。

修改环境变量后，在原启动终端停止并重新启动后端（管理员页面保存的文本配置无需重启），再按 README 打开客服工作台。不要同时启动两个进程操作同一业务数据库，也不需要重建数据库。

- 管理员设置中的模型配置状态只说明变量存在。实际连通验证和新建营销任务会调用外部服务，可能消耗账户额度。
- 先用一个完整型号、场景和平台运行，查看实际来源是否为 ima，再检查导出的资料和图片依据。
- 出现 401/403 时核对对应服务权限和凭证；搜索为空应继续目录回退；图片不足或来源冲突按界面处理。
- 提交材料只展示脱敏状态、资料标题、来源说明和结果，勿截图配置文件或完整接口响应。

## 6. 提交前检查

```powershell
python -m unittest scripts.test_submission
python scripts/prepare_submission.py --check
```

扫描会核对本地私有配置中的密钥值与实际文本服务地址是否出现在拟公开文件中，并拦截常见密钥格式。通过扫描不替代人工审阅。仓库发布副本仅暂存白名单文件；本机知识索引、客户数据、图片原件、历史私有验收响应不上传。
