# ima 优先与本地回退：接入和验收

日期：2026-10-18。本轮只做本地接入与真实验收，没有发布或提交。

## 当前行为

新营销任务使用 `MARKETING_KNOWLEDGE_SOURCE=ima_first`：优先调用指定 ima 共享知识库；鉴权、网络、超时、返回结构、目录定位、原文或图片下载失败时，整项任务回退本地 ZIP。界面与导出记录实际来源和回退原因，不混用两边的事实和图片，也不把本地结果作为 ima 图源证明。

生成阶段的资料冲突、事实错误或合规问题不会通过切换来源绕过检查。已有作品重新核验使用原来源：ima 作品使用该次检索保存的资料与原图快照，本地作品按保存的资料编号读取本地版本记录。ima 快照缺失或完整性失败需要重新创建任务，不将旧作品悄悄改标为本地。

## 检索与来源

接口协议依据官方 Skill 1.1.10；应用调用只读接口 `search_knowledge_base`、`search_knowledge`、`get_knowledge_list`、`get_media_info`。密钥只发送给 `https://ima.qq.com`；读取原文、图片时不会将账号凭证转发到存储域名，临时签名下载链接也不进入前端和导出。

每次任务按型号与场景搜索，再逐级核对 `P1-产品参数库 / 系统类别 / 完整型号`，避免混入相近型号、竞品或价格政策库。空搜索仍可按目录定位。读取对应产品事实、卖点与限制及同目录原图；按场景选择最多六张不同内容的原图，保留路径、取得时间与 SHA256。全部成功后才启用来源快照。

产品选择仍沿用已有十个产品的目录映射，不等于已导入 ima 全库。目录改名或新增型号需要更新映射。单请求最长 25 秒，总检索最长 150 秒；失败走回退，不无限重试。

## 配置与备份

- ima 凭证单独保存在根目录 `.env.ima`，避免旧编辑标签覆盖常规 `.env`；两者均被忽略。
- 读取优先级：进程环境变量 → `.env.ima` → `.env`。测试显式清空凭证并选择本地模式。
- `.env.ima` 中配置 `IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY`、`MARKETING_KNOWLEDGE_SOURCE=ima_first`；值不放入源码或 `VITE_*` 变量。
- ima 缓存位于业务数据目录下 `ima/`，其中 `snapshots/` 为每篇作品的资料快照，`records/` 为来源记录，`objects/` 为原图。既有本地资料不改标。
- 迁移时需要同时备份业务数据库、`knowledge/`、`ima/`、`assets/` 和私有配置，仅备份数据库不能恢复资料图片。
- ima 原图接口要求客服登录；匿名客户产品目录继续使用已有本地产品资料。
