## 凭证填写规则

后续接入时使用官方约定的服务端环境变量：

```text
IMA_OPENAPI_CLIENTID=<在本机私有配置填写>
IMA_OPENAPI_APIKEY=<在本机私有配置填写>
```

当前后端尚不读取这两个变量，提前填写不会自动接通。不得放入 `VITE_*` 变量，因为这些可能进入浏览器构建产物。不要覆盖已有 `.env` 中的文本或图片服务配置，也不要将凭证作为 shell 命令参数、公开文件或录屏内容。

知识库 ID 从接口返回读取并仅供服务端使用，不需要你手工猜测或在聊天里发送。

## 准备好之后的接入工作

1. 检查官方 Skill 的使用说明和当前返回结构，再在现有 `KnowledgeSource` 抽象之上实现 ima 提供器，保留本地资料读取能力与历史引用。
2. 识别当前接入账号，调用 `search_knowledge_base`，按指定库名找到 `kb_id`，展示脱敏连接状态。
3. 调用 `search_knowledge` 按完整型号和任务检索；搜索为空时必须回退 `get_knowledge_list` 浏览目录，不能直接判断无权限。
4. 用 `get_media_info` 读取原文或访问链接，提取事实和同型号原图；保留资料 ID、名称、检索时间、版本或摘要、原链接及图片出处。
5. 把真实来源接入创作、核验、查看依据和导出；只有拿到实际 ima 调用证据，才能把当前“本地 ZIP / ima 未验证”的标记改为对应真实状态。
6. 实测权限失败、网络超时、空搜索、相近型号、图不足和来源冲突，错误时不伪造内容、不回退模型记忆补参数。

## 接入验收标准

- 同一账号能够找到指定共享库，连接状态与真实接口返回一致；界面不显示完整 Client ID / Key。
- 现场切换产品，能够重新读取对应资料和同型号图片，记录真实来源。
- 空搜索能演示目录回退；图片数量不足会阻止正式稿通过。
- 对旧作品继续保留原来源，不能把已有官网 ZIP 图片批量改标为 ima 图片。
- 使用 ima 来源重新运行比赛案例和完整录屏。此前的本地图源案例不追溯冒充 ima 验收。

你准备好后，只需告知：账号已登录、共享库能打开、凭证已保存在本机、官方 Skill 的本地路径。不要发送密钥明文。
