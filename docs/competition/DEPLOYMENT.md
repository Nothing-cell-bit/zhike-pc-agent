# 完整工作台的魔搭部署

> **当前状态：魔搭部署还是有点问题。** 已有完整应用部署代码和临时模型转发方案，但云端稳定性及完整业务流程尚未验收完成。临时方案依赖用户电脑、模型连接、网关和隧道持续运行，不能视为已完成独立云端托管。

`Dockerfile` 构建原 React 前端并运行 FastAPI，入口为 `python -m backend.cloud`，监听 `0.0.0.0:7860`。该运行方式与原静态项目介绍页不同；只有部署成功并验证后才可称为完整网站上线。

## 私有变量

在魔搭「部署设置 → 密文管理」中设置 `TEXT_API_BASE`、`TEXT_API_KEY`、`IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY`、`CLOUD_ADMIN_PASSWORD`。真实值只作为运行时私有变量，不进入 Git、Dockerfile、镜像构建参数、页面、PDF 或日志。

本次部署将上述值作为 JSON 对象集中放在一个私有密文变量 `ZHIKE_PRIVATE_CONFIG` 中；入口只接受这些已列出的变量名，解析后移除 JSON 环境变量，不将内容写入日志。也支持逐项配置独立密文变量。两种方式均不得把真实值写入公开配置。

`CLOUD_ADMIN_USERNAME` 默认 `admin`。首次启动创建管理员；已有管理员不会被覆盖、改密或重建。首次密码至少 16 位，应随机生成并仅在团队私有位置保存。

## 数据边界

- 数据保存在 `/mnt/workspace/zhike`。魔搭平台的重命名、转移或存储策略仍可能影响数据，正式使用前应另行备份。
- 不上传本机业务数据库、客户聊天、初始化密码、知识库 ZIP 或原图。
- 初次启动使用已授权 ima 账号读取产品目录，只初始化型号和路径；不会伪造本地产品参数或图片。参数与原图在员工新建营销任务时实际读取并保存在服务端私有快照中。
- 通用容器默认严格 `ima` 模式。当前空间经用户另行授权，私有同步 10 款产品、20 份文档、68 张图片（不含客户、凭证和报价表），并启用 `ima_first`。读取失败时使用明确标注的本地回退。新取得的 ima 原图仍按员工权限访问；授权的本地产品缓存用于原网站的产品展示与回退。
- 公开访客消息只有在客服认领会话后才触发自动需求分析；其他模型操作保留员工登录权限。

## 嵌入与登录

云端适配器只允许 `https://modelscope.cn` 与 `https://www.modelscope.cn` 嵌入；保留原有同源校验和接口权限。会话 Cookie 使用 HttpOnly、Secure、SameSite=None 和 Partitioned，以适配跨站 iframe。可用直达应用地址访问 `/staff` 登录客服工作台。

魔搭转发请求会改写 Host。`CLOUD_PUBLIC_ORIGIN` 配置该应用唯一的公开 HTTPS 域名，适配器只对与它完全一致的 Origin 规范化 Host；其他站点仍按原规则拒绝，不使用通配符放开跨站请求。

## 验证

发布前检查 Docker 构建、前端页面、管理员登录、访客隔离、跨站拦截、实际 ima 检索、生成核验及数据目录。Docker 需要魔搭账号满足平台的阿里云绑定与实名条件；此条件由平台判断，不能由源码绕过。

公开魔搭仓库中的 Apache 2.0 标记仅覆盖介绍文案；部署包装下载 GitHub 上的指定版本来运行，不能据此将整个 GitHub 源码重新授权为 Apache 2.0。

## 内网文本模型的临时访问

当前部署采用本机转发链路；本机直连上游读取模型列表已成功，但尚未据此确认学校接口对任意校外网络或魔搭云端开放。经用户明确允许，使用 Cloudflare 临时隧道连接本机认证网关。`scripts/model_gateway.py` 仅监听本机 `127.0.0.1:18739`，只开放带独立 Bearer 凭证的模型列表和指定模型非流式聊天请求；上游密钥不转发给云端。请求限制为 250 KB、最多 8192 输出 token、每分钟 30 次、同时 2 次。

私有配置在本机 `data/deployment/model-gateway.json`；魔搭的 `ZHIKE_PRIVATE_CONFIG` 使用隧道地址与独立网关 token。电脑、原模型连接、网关和 cloudflared 都需保持运行。临时隧道重建后地址可能变化，需要更新平台密文变量并重新部署；这不是独立于用户电脑的长期托管。

本次后台进程编号记录在 `data/deployment/gateway.pid` 与 `tunnel.pid`，日志也只保存在该私有目录。不得公开这些配置文件、隧道凭证或上游服务地址。

## 私有产品缓存

经用户授权的产品缓存通过同一认证网关单独传输，不放入任一公开 Git 仓库或 Docker 镜像。容器仅保存 `CLOUD_CACHE_SHA256` 校验摘要，启动时下载并验证文件清单、路径、数据库结构和图片哈希，再安装到私有运行目录。已安装且摘要一致时不重复下载。传输上限 25 MB、解压上限 40 MB；拒绝越界路径、符号链接、客户数据表和报价记录，替换知识索引前保留旧索引。

2026-10-18 的实际云端生成曾被 ima 220021 拦截，明确提示当天读取次数已达上限。启用缓存回退是为了处理该限制，不把缓存产物记作新 ima 成功案例。

## 管理员自行切换文本模型

管理员登录原工作台，在左下角账号菜单进入「管理设置 → 服务连接 → 语言模型」，填写公网 HTTPS 基础地址、模型 ID、API Key，保存并测试。无需修改源码或重新部署。具体兼容要求、密钥保留规则及私有文件位置见 [API 配置手册](API_CONFIGURATION.md#在线自行配置管理员)。

页面自定义配置优先于部署默认变量，保存在持久卷 `/mnt/workspace/zhike/private/text-model.json`；部署时应保留该目录，不把它提交、构建进镜像或提供静态下载。恢复默认会删除该自定义文件。当前平台默认仍为本机隧道；只有用户切换到云端能直接访问的模型后，文本功能才摆脱本机开机要求。已有缓存保持不变，ima 仍使用原私有凭证与额度。
